# BE THE BRAND — Digital Business Card

Premium mobile-first digital card for BE THE BRAND / Jothi Swaroop.

## Quick setup on GitHub

1. Create a new public GitHub repository.
2. Upload everything inside this folder, keeping the `assets` folder intact.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you a live URL such as:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Files

- `index.html` — page structure/content
- `style.css` — premium responsive design
- `script.js` — reveal animations and smooth scrolling
- `assets/btb-logo.jpg` — BE THE BRAND logo
- `assets/jothi-swaroop.jpg` — founder photo

## Important

The WhatsApp, email, Instagram and LinkedIn links are already configured.

The page is static, so there is no database, backend or server required.
