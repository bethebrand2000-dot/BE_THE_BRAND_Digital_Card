# BE THE BRAND — Premium Digital Business Card

A mobile-first digital business card for BE THE BRAND / Jothi Swaroop.

## What's included

- Sticky top navigation
- Always-visible WhatsApp, Call and Add Contact actions
- Mobile bottom contact dock
- One-tap downloadable vCard
- Founder photo and BTB logo
- Performance Marketing, Brand & Content, AI & Automation, Digital Presence
- Premium responsive design
- GitHub Pages compatible
- No backend or database

## GitHub Pages

1. Create a public repository.
2. Upload all files from this folder into the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save and open the generated Pages URL.

Keep the image files in the repository root:
- `btb-logo.jpg`
- `jothi-swaroop.jpg`

Do not move them into another folder unless you also update the paths in `index.html`.
