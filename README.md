# BE THE BRAND — Digital Card v3

## Important
This version is intentionally **self-contained**: the CSS is embedded inside `index.html`. This prevents GitHub Pages from showing an unstyled/raw page if `style.css` is not uploaded or cannot be resolved.

### Upload all files to the repository root
- index.html
- btb-logo.jpg
- jothi-swaroop.jpg
- Jothi-Swaroop-BE-THE-BRAND.vcf

Then enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root).

The top bar always exposes WhatsApp, Call and Save Contact. On mobile, the bottom bar stays visible too.
